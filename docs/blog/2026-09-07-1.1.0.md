1.1.0 把本地文件预览接入了 Vertree。现在可以在 Windows 右键菜单选择“预览文件”，也可以从版本树节点打开历史文件，快速确认内容后再决定是否用原软件编辑。

<!-- truncate -->

## 预览不需要先建立版本树

任意文件都可以尝试预览。Windows 和 macOS 在应用内显示，Linux 使用本机浏览器；命令行也支持 `vertree preview "文件路径"`。

通用格式能力由配套的 [Office-Viewer](https://github.com/w0fv1/Office-Viewer) 仓库维护，Vertree 复用其前端模块，文件内容在本机处理。

## 这次补齐了哪些内容

除了文档、表格、PDF、常见图片和文本，还扩展了 Office 模板与宏文档、OpenDocument、音视频、电子书、EML、HEIC/HEIF、CUR、Parquet、CRX 和 Java class 等格式。

PPTX 可查看幻灯片画布并翻页，PSD 显示保存的合成图，XMind 显示可缩放和折叠的主题层级。完整格式、展示方式和限制请查阅[格式支持表](/docs/tutorial-usage/preview)。

## 大文件与未知格式

固定的 64 MiB 上限已经取消。媒体、PDF 和 Parquet 支持按需读取，其他格式仍受解析器和资源条件影响；开始预览时仍需建立临时磁盘快照。

未知扩展名只检测是否为文本，可识别则显示正文，否则提示不支持。十六进制回退和多余的说明文字已经移除。

## 菜单和界面整理

传统 Windows 菜单的注册、单项开关和折叠布局使用统一逻辑，Windows 11 新菜单仍单独控制。连续打开预览时自动关闭上一个窗口，去掉重复文件名，“用系统程序打开”改为带提示的图标按钮，版本树外层边框也已移除。

文档站同步重写了安装升级、备份监控、预览格式、系统入口、分享、排障和开发构建说明。可以从[文档首页](/docs/intro)按任务查找。
