1.1.4 修复 Windows 任务栏 Logo 白底和退出拖延，并统一各平台与官网使用的 Logo 资源。

<!-- truncate -->

## 任务栏图标

运行窗口明确指定公共透明 ICO，并与安装器创建的快捷方式使用相同的应用标识，避免升级后继续选取旧的图标关联。修复已在实际 Windows 任务栏确认。

## 退出流程

主页、托盘和本地 API 现在使用同一个退出入口。后台服务关闭、托盘图标移除后，Windows 进程直接结束，避开引擎销毁时的原生异常。实测退出约 0.19 秒，退出码为 0；实际耗时取决于运行环境。

## 公共 Logo

Logo 以公共目录中的 PNG 和 ICO 为源。官网直接读取公共文件，macOS 和 Windows 包身份所需的不同尺寸由脚本生成，减少重复维护。

[下载 1.1.4](https://github.com/w0fv1/VerTree/releases/tag/V1.1.4)。Windows 用户退出旧版后覆盖安装即可，文件预览功能保持可用。
