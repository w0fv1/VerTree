Vertree 1.2.0 新增文件预览图 API：传入本机文件绝对路径，后台直接返回 PNG。预览图通过 Office-Viewer 的共享渲染模块生成，不弹窗，也不替换当前预览。

<!-- truncate -->

## 文件预览图

`POST /api/v1/preview-images` 支持宽高、PDF/PPT 页码、工作表和视频时间点。未知扩展名按内容检测文本，未知二进制和音频等无可视内容的文件明确返回不支持。

Word 与连续文本目前导出首屏；Windows 使用 WebView2，macOS 使用 WKWebView，Linux 后台生成需要安装 Chromium 或 Google Chrome。

Office-Viewer 增加共享导出函数和桌面导出入口。两边的支持格式来自同一个 registry，构建时生成能力清单。

## 自动化接口

新增预览控制与状态、格式能力、版本恢复与备注修改、文件比较、设置读写、批处理、异步任务、SSE 实时事件和运行诊断。版本恢复前保留当前文件备份，同时修复连续备份可能复用分支编号、覆盖旧备份的问题。

异步取消在安全边界生效；SSE 可回放最近 256 条事件。API 仅监听本机，业务请求需要 Bearer Token。

完整用法见[本机 API 文档](/docs/tutorial-develop/local-api)。仓库中的 `tools/start_preview_demo.cmd` 可启动本地预览测试页。
