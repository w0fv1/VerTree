这一轮把 Windows 文件清理和占用诊断拆成两个独立功能，同时整理菜单设置、首页与文档。**这是开发进展，不是正式安装包的发布公告。**

<!-- truncate -->

## 两种动作，分别确认

快速删除面向大文件和海量小文件。目标从右键菜单带入，或点击选择卡片补充；确认永久删除与进程终止风险后再执行，不展示并发参数和历史任务面板。

解除占用以进程卡片展示使用文件的程序，按需展开详情、刷新或进行管理员扫描。“结束任务”独立确认，本身不删除文件。

不会因为强调“快”就自动改 ACL、关闭安全软件或结束受保护进程。取消不能撤销已完成的永久删除。

## 设置更一致

Windows 11 与经典菜单的单项设置共用相同的滑动开关样式，选择状态仍然独立。应用设置只以 `settings.json` 为准，不再导入旧配置或回退 `.previous`。

首页保留紧凑的“监控”“设置”和无边框退出图标；文案每次完全启动随机一条，同次运行不变。背景卡片按可用宽度缩放，具备最小值、上限和窄窗退让规则，不再由句子长短决定宽度。

## 文档与发布边界

官网增加功能与下载页，用户指南按备份、版本树、监控、菜单与文件工具组织。更正旧快照目录、固定菜单项数量和旧模块路径，同时保留历史发布文章的时间语境。

当前公开正式版在审计时为 2.0.1。以上新增能力必须等明确版本发布后，才能视为公开安装包已提供。使用流程见[快速删除](/docs/tutorial-usage/fast-delete)、[解除占用](/docs/tutorial-usage/file-locks)和[设置说明](/docs/tutorial-usage/settings)。
