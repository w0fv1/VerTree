3.0.0 把 Windows 快速删除与解除占用做成两个独立功能，同时整理菜单、配置和首页，让文件操作入口保持明确。

<!-- truncate -->

## 文件工具各自做好一件事

从文件右键菜单进入[快速删除](/docs/tutorial-usage/fast-delete)或[解除占用](/docs/tutorial-usage/file-locks)。前者处理文件和目录，后者查看并按需结束占用进程。页面不要求手工输入路径，也不展示并发选项或任务历史。

**删除是永久删除，不进入回收站，并可能结束可处理的占用程序。确认前保存工作；已删除内容不能撤销。** 系统保护、权限和身份检查仍然生效，没有“绕过所有阻碍”的承诺。

## 菜单与配置统一

Windows 11 和经典菜单采用同样的单项开关样式，各自保留选中状态。配置只使用 `settings.json`，不导入旧配置或恢复 `.previous`；已有有效的 2.x 设置与监控任务继续保留。

## 首页更克制

卡片改为比例宽度并保留优选最小值与最大值，小窗口可缩窄和滚动。品牌区与按钮间距增加至 40，按钮仍紧凑；退出只保留图标。10 句文案在完整启动时随机选择，同一次运行中保持不变。

## 官网与文档一起更新

首页、功能页、下载页和导航重新排版，文档按实际任务组织。修正自动快照目录和菜单配置的过时说明，补充使用截图、常见问题和开发边界。站内链接、资源、浅深色及手机布局纳入构建检查。
