本次为不兼容升级：重组版本、快照和监控架构，并修正 Windows MSI 安装包。

<!-- truncate -->

## 升级前请注意

- 使用新的 settings.json 配置和 monitorTasks 任务格式，不读取或迁移旧 config.json。升级后请重新设置偏好并添加监控任务。
- 自动快照保存在源目录的 `.vertree/snapshots/<任务 UUID>` 中，通过清单确认归属。旧 *_bak 文件保持原样，但不会自动导入或显示在新快照列表中。
- 手动版本仍是普通文件，继续按文件名识别版本关系。
- 本机 API 删除 /backups、/version-files 和任务 /backups 路由。手动版本统一使用 GET/POST /api/v1/versions；自动快照使用 GET /api/v1/snapshots 和任务 /snapshots。任务使用 UUID 和 enabled；版本树返回 entries、parents、diagnostics。
- SSE 游标改为 sessionId:序号，进程重启后重新查询状态并订阅。

## 可靠性与架构

- UI、CLI、托盘和 HTTP 共用版本命令，集中处理创建、分支、标签、恢复和同名冲突。
- 手动版本与自动快照共享写入协调；新文件暂存后发布，不覆盖同名目标。
- 快照成功提交后才执行保留清理，只删除已验证归属的快照，保留未知文件。
- 监控失败不推进成功时间；复制期间的后续变化继续处理。监听与复制故障独立记录和重试，页面实时同步任务变化。
- 统一 Windows 短路径别名处理；原生文件发布在同一次调用内捕获错误码，可靠报告同名冲突。
- 启动失败回收资源，退出等待正在进行的写入；设置读取无写入副作用。
- 新增模块依赖检查与 CI，禁止反向依赖、跨模块内部引用及循环依赖，无历史白名单。

## Windows MSI 修复

- 修正公共桌面和开始菜单目录，避免快捷方式被安装到 C:\ 根目录。
- 修正快捷方式组件 KeyPath，保留 WiX ICE 校验。
- 发布前检查 MSI 目录，并在 Windows CI 中执行安装、快捷方式目标检查和卸载，失败阻止发布并保留日志。

## 验证与边界

本地通过 98 项 Flutter 测试、静态分析、架构检查、Windows Debug 构建与文档构建。正式安装产物由 GitHub Actions 构建和校验。

当前未实现跨进程文件事务日志；内部协调不能阻止其他编辑器并发修改文件。macOS/Linux 原生文件发布行为仍需持续补充对应平台的运行测试。
