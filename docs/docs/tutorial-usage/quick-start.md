# 完成第一次备份


这一页只做一件事：给一个文件留下可辨认的阶段版本。先用可丢弃的测试副本练习，不在唯一的重要文件上试操作。

## 1. 保存当前内容

在原软件中打开 `方案.docx` 并保存。Vertree 备份的是磁盘上的内容，编辑器中尚未保存的修改不会进入副本。

## 2. 创建一份带备注的版本

在 Windows 资源管理器中右键文件，选择 Vertree 的“备份文件”。输入“客户确认”等简短备注，再完成备份。需要直接复制、无需本次备注时可用“快速备份”。其他平台的入口见[系统菜单](entry-points.md)。

成功后，原目录会出现新的版本文件，例如：

```text
方案.docx
方案#客户确认.0.1.docx
```

两者都是普通文件。先确认新文件存在，并可用原软件打开。

## 3. 在版本树中查看

对该文件选择“查看文件版本树”。在节点菜单中打开“预览”，先看内容再决定继续编辑哪份文件。预览不修改文件；不支持的格式仍能用原软件打开。

![使用示例文件展示的版本树](/img/usage/version-tree-page.png)

## 4. 再决定是否需要自动监控

经常编辑这份文件时，从首页进入“监控”，添加文件任务。默认最小备份间隔为 5 分钟，每任务保留 50 份已识别快照。自动快照在 `.vertree/snapshots/<任务 UUID>` 内，不会直接成为原目录里的手动版本节点。

重要交付节点仍建议手动备份。监控只在 Vertree 运行时有效，也不承诺每次保存都产生快照。

## 到这里，你应该能确认

原目录有一份带版本号的新文件；版本树可看见它；可以用预览或原软件核对内容。缺少其中任何一项，先看[常见问题](troubleshooting.md)，不要继续叠加不确定的操作。

接下来阅读[版本树与分支](version-tree.md)、[监控与快照](monitoring.md)，或[设置菜单入口](entry-points.md)。
