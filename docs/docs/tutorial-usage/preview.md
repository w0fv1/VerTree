# 文件预览与格式支持

文件预览用于快速查看当前文件或历史版本，全部为只读。它不修改原文件，不执行宏，也不把文件内容上传到云端。

## 打开预览

| 入口 | 操作 |
| --- | --- |
| Windows 资源管理器 | 右键文件 → “预览文件”；Win11 新菜单位于 `Vertree` 子菜单 |
| 版本树 | 右键目标节点选择“预览”，或在节点打开对话框中选择预览 |
| 命令行 | `vertree preview "文件路径"` |

无需先把文件加入版本树或开启监控。Windows 和 macOS 在应用内显示，Linux 从预览对话框打开本机浏览器。

应用内同时保留一个预览窗口。打开另一个文件会关闭上一个预览，并回收旧文件会话。Linux 浏览器中已经打开的标签页可能仍保留画面，但旧页面不能继续读取文件。

预览右上角的“用系统程序打开”图标可调用文件的默认关联软件；将鼠标停在图标上可查看提示。需要编辑或查看原版排版时可使用这个入口。

## 支持格式

下表对应 Vertree 1.1.0 固定使用的 Office-Viewer 版本。扩展名不区分大小写；实际预览效果还取决于文件内容、编码、是否损坏及是否加密。

| 类别 | 扩展名 | 预览方式与边界 |
| --- | --- | --- |
| Word / 文本文档 | DOCX、DOCM、DOTX、DOTM、ODT、OTT、FODT、RTF | 正文与文档结构；复杂版式可能与原软件不同 |
| 表格 | XLSX、XLSM、XLTX、XLTM、XLS、CSV、TSV、ODS、OTS、FODS | 表格内容；旧 XLS 支持有限，不保证完整工作簿功能 |
| PowerPoint | PPTX、PPTM、PPSX、PPSM、POTX、POTM | 幻灯片画布、翻页、缩放和备注；不播放宏或动画 |
| OpenDocument 演示 | ODP、OTP、FODP | 逐页文本和备注，尚不是完整幻灯片画面 |
| PDF | PDF | 页面显示取决于平台 WebView / 浏览器能力；另有文本提取 |
| 常见图片 | PNG、JPG、JPEG、PJP、PJPEG、GIF、WEBP、BMP、ICO、AVIF、APNG | 图片显示；部分编码取决于浏览器支持 |
| 其他图片 | HEIC、HEIF、CUR、TIF、TIFF、ICNS、SVG、SVGZ | 本地转换或渲染，SVG 不加载外部资源 |
| Photoshop | PSD | 保存的合成图和图层信息；需要文件内包含合成图 |
| 思维导图 | XMIND | 主题层级、多画布、缩放与折叠；原始样式、关系线、图片和附件尚未完整复现 |
| 音频 | MP3、WAV、OGG、OGA、OPUS、FLAC、M4A、AAC | 本地播放控件；是否能解码取决于系统浏览器 |
| 视频 | MP4、M4V、WEBM、OGV、MOV | 本地播放控件；容器扩展名相同也可能使用不同编码 |
| 电子书 / 漫画 | EPUB、FB2、CBZ | 章节阅读或图片翻阅；不支持加密电子书 |
| 邮件 | EML | 主题、收发件人、正文和附件名称；不能在邮件预览中打开附件 |
| 压缩包 / 包文件 | ZIP、CRX、JAR、VSIX、APK、TAR、TGZ、TAR.GZ、7Z、RAR | 条目列表；CRX 支持版本 2/3，不安装扩展、不运行包内程序 |
| 列式数据 | PARQUET | 字段结构和每页 100 行数据，可按需读取；LZO 压缩暂不支持 |
| Java 字节码 | CLASS | 本地反编译为源码，不执行 class，不需要安装 Java；缺少依赖可能影响还原 |
| 字体 | TTF、OTF、WOFF、WOFF2 | 字体样张 |
| Markdown / 网页 | MD、MARKDOWN、HTML、HTM、XHTML | 只读渲染，移除不安全内容，不运行网页脚本 |
| 结构化文本 | JSON、YAML、YML、XML、TOML | 文本或结构化内容 |
| 文本 / 源码 | TXT、LOG、JS、TS、TSX、JSX、CSS、RS、PY、GO、JAVA、C、CPP、H、HPP、CS、SQL、SH、PS1 | 只读文本，不运行代码 |

Office 的宏文档扩展名表示可以读取文档内容，**不表示运行其中的宏**。压缩包预览也不等于递归预览包内每一个文件。

## 未知格式怎么处理

未知扩展名会做简单内容检测：可识别的 UTF-8 或带 BOM 的 UTF-16 文本直接显示正文，否则显示“不支持预览此文件”。例如 `.norm` 如果实际存放纯文本，就能按文本阅读；若是二进制专有格式，则显示不支持。

不会显示十六进制、文件元信息拼接或“文本尝试”提示。无 BOM 的旧编码文本可能无法正确识别；可以用原软件打开，或另存为 UTF-8 副本后预览。

目前仍没有专用预览器的典型格式包括旧版 **DOC / PPT、MSG、MOBI / AZW** 和加密电子书。备份和版本管理不依赖是否存在预览器。

## 大文件与资源占用

1.1.0 已取消 **64 MiB 固定上限**，但这不意味着任何体积的文件都能立即打开。

- 开始时会复制一份临时磁盘快照，所需临时空间约等于原文件大小；大文件可能先等待复制完成。
- 普通图片、字体、音视频和 PDF 可直接从本机文件地址加载；PDF、媒体和 Parquet 支持分段读取。
- Office 文档、压缩包、文本及部分图片转换器仍需读取完整内容，解析后的内存占用可能高于原文件体积。
- 关闭预览会清理当前会话与快照。Java 反编译会在关闭或超过 30 秒时停止。

因此，大视频和大表格可能表现不同。若预览持续失败，先用较小文件确认功能正常，再检查空闲磁盘、可用内存和文件完整性。

## 本地处理与外部资源

预览页面与文件由本机临时服务提供，关闭后地址失效。文档中的外部图片、字体和联网资源不会自动下载，这可能使某些邮件或网页的显示与在线版本不同。

预览、[局域网分享](sharing.md)和[本机自动化 API](../tutorial-develop/local-api.md)是三个独立功能。打开预览不需要启用 API，也不会创建分享链接。

预览出现空白、格式不支持或播放失败时，见[常见问题](troubleshooting.md)。开发者可阅读[预览架构](../tutorial-develop/preview-architecture.md)。
