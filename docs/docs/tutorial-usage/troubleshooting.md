# 常见问题与排查


先记下应用版本、系统、操作入口与错误文字。涉及删除或结束进程时，先保存工作，用可丢弃副本复现，不在唯一的重要文件上反复尝试。

## Windows 右键菜单没有预览文件

检查当前正在运行的安装目录，在设置中确认对应菜单总开关和“预览文件”单项。Windows 11 新菜单与“显示更多选项”是两组设置，不能只检查其中一组。

便携目录移动或多个安装版本并存会使注册入口指向旧位置。用准备保留的版本重新应用菜单。Windows 11 新菜单还依赖包身份注册；失败时先用经典菜单，再看[安装说明](install.md#windows)。

## 找不到删除、解除占用或 Win11 单项开关

这些入口从 **Windows 3.0.0** 开始提供。先检查安装版本、对应菜单总开关与单项开关。删除与解除占用只从文件右键菜单进入，首页和标题栏没有独立快捷按钮。

## 右键出现重复的 Vertree 项目

核对是否同时使用安装版和便携版，再在准备保留的版本里重新应用设置。新旧两种 Windows 菜单各有一组属于正常情况；同一组出现重复才需要排查。不要自行批量删除注册表项或全局重启其他软件。

## 预览空白或初始化失败

先分别预览一个小 TXT 和 PNG。

| 结果 | 下一步 |
| --- | --- |
| Windows 全部失败 | 安装或修复 WebView2 Runtime，再启动应用 |
| 提示缺少资源 | 重新安装完整包；源码运行先构建 Office Viewer assets |
| 只有一个文件失败 | 检查文件完整性、密码保护和格式表中的边界 |
| 大文件准备很久 | 检查临时磁盘空间；创建预览快照需要复制文件 |
| Linux 旧标签页读不到文件 | 原会话已关闭，从 Vertree 重新打开预览 |

需要精确版式或编辑时，使用“用系统程序打开”。文件格式与显示内容见[预览指南](preview.md#支持格式)。

## 未知格式为什么显示不支持

未知扩展名只检测可识别文本，二进制专有格式需要对应解析器。改扩展名不是格式转换，也不会显示十六进制回退。旧 DOC/PPT、MSG、MOBI/AZW 等限制见[格式边界](preview.md#未知格式怎么处理)。

## 取消 64 MiB 上限后，大文件为什么仍打不开

取消的是入口拦截，解析器和内存仍有边界。快照占用临时空间，Office、压缩文件等可能整份读入内存，解压后还可能比原文件更大。不要把“无固定上限”理解为无限资源。

## 视频、幻灯片或设计稿与原软件不同

媒体是否可解码取决于系统 WebView / 浏览器。PPTX 不完整复现所有动画与版式；ODP 主要显示文本；PSD 依赖保存的合成图；XMind 的样式、关系线和附件也有边界。用原软件核对，避免将预览当作最终渲染校验。

## 监控没有生成备份

确认 Vertree 仍运行、任务已启用、文件路径存在且发生过保存。最小间隔从上次成功快照算起，间隔内保存不一定立即生成新副本。检查任务状态和日志，再打开 `.vertree/snapshots/<任务 UUID>` 查看，而不是只找旧 `*_bak`。

## 移除任务后，备份为什么还在

移除监控与清理快照是独立操作。任务移除后保留归档身份和快照；清理动作只删除已识别的本任务快照。完整规则见[监控指南](monitoring.md)。

## 版本树少了文件或分支

检查文件是否在同目录、逻辑名称与扩展名是否一致、是否手动改过版本段，再刷新画布。缺失父节点、重复版本可产生诊断；磁盘文件存在不保证它能连入当前显示树。自动快照也不会直接变成手动版本节点。

## 文件删除未完成

先看未完成项目的错误类型：占用、权限、设备断开与身份变化不是同一个问题。3.0.0 会按确认授权处理只读和可处理的占用，但不会自动改 ACL、夺取所有权或结束受保护进程。停止不是撤销。详见[快速删除](fast-delete.md)。

## 文件已删除，空间却没立即增加

名称移除与实际空间回收可能因其他打开句柄等原因错开。逻辑文件大小也不等于分配空间，不能把处理大小直接当作已释放容量。不要因此对相同路径无限重试；新出现的同名文件是另一个对象。

## 解除占用没有发现进程

没有可访问结果不等于没有任何占用。检查是否提示扫描不完整，必要时管理员扫描；NAS 上的其他客户端不属于本机进程扫描范围。仍无法操作时排查权限和设备状态，见[占用指南](file-locks.md)。

## Linux 没有托盘或 Files 菜单

GNOME 可能缺少 AppIndicator 扩展或 Nautilus Python 支持。先从主窗口使用，再按设置中的环境提示补齐；具体见 [Linux](../linux.md)。关闭预览后浏览器标签页保留属于正常情况，会话地址已撤销。

## API 返回 401 或无法连接

API 默认关闭。启用后从设置复制实际地址和本次进程 Token，业务请求携带 Bearer 认证。端口占用会递增，重启后凭据可能改变。见[本机 API](../tutorial-develop/local-api.md)。

## 反馈时附什么

提供版本、系统、文件类型、可复现步骤、错误文字和可公开的最小样例。日志、截图可能包含个人路径；先移除 Token、分享链接与私密内容，再提交到 [GitHub Issues](https://github.com/w0fv1/VerTree/issues)。
