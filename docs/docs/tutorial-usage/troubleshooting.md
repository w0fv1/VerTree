# 常见问题

## Windows 右键菜单没有预览文件

1. 先确认当前运行的是 1.1.0 或更新版本。
2. 在设置页检查传统菜单的“预览文件”是否开启。
3. Windows 11 分别检查新菜单与“显示更多选项”中的传统菜单。传统菜单的逐项选择不会同步改变 Win11 新菜单。
4. 如果移动过便携目录或保留了多个安装目录，在当前应用内重新应用菜单设置。

Win11 新菜单还依赖安装包建立的包身份。若它未成功注册，可先使用传统菜单；开发者排查包身份和签名时见[构建说明](../tutorial-develop/develop.md#windows)。

## 右键出现重复的 Vertree 项目

先检查是否有旧版、便携版与新版同时注册入口。使用准备保留的版本重新应用菜单设置；1.1.0 会迁移并清理它认识的旧菜单项。不要随意删除无关注册表项。

## 预览空白或初始化失败

先分别预览一个小 TXT 和 PNG，以区分预览环境问题与特定格式问题。

| 结果 | 下一步 |
| --- | --- |
| Windows 所有文件都无法预览 | 安装或修复 WebView2 Runtime，重启 Vertree |
| 提示缺少预览资源 | 安装包整体重新安装；源码运行先执行 `python tools/build_office_preview.py` |
| 仅某个文件失败 | 用原软件检查完整性、加密状态及格式，参考[格式表](preview.md#支持格式) |
| 大文件长时间准备中 | 检查临时磁盘空间和内存；开始预览前需要复制文件快照 |
| Linux 浏览器旧页面无法加载 | 旧会话可能已关闭；从 Vertree 重新打开预览 |

失败后可通过预览窗口右上角的系统打开图标，调用默认软件查看文件。反馈问题时提供应用版本、平台、扩展名和错误文字，必要时附可公开的最小样例。

## 未知格式为什么显示不支持

未知扩展名只尝试识别文本。UTF-8 或带 BOM 的 UTF-16 内容可以按文本阅读，专有二进制格式需要对应解析器。改扩展名不会把二进制文件转换成文本。

十六进制与文件元信息回退已经移除。旧 DOC/PPT、MSG、MOBI/AZW 等尚无专用预览；详见[当前边界](preview.md#未知格式怎么处理)。

## 取消 64 MiB 上限后，大文件为什么仍打不开

取消的是应用入口的固定拦截。大文件仍需要临时磁盘快照，部分解析器还会把全部内容读入内存。压缩包或复杂 Office 文件解压后的体积可能远大于源文件；媒体、PDF、Parquet 的按需读取通常更有利于大文件。

## 视频有声音没画面，或提示不能播放

MP4、MOV 等扩展名标识容器，内部视频和音频编码可能不同。播放依赖系统 WebView / 浏览器的解码能力；可以用系统播放器打开，或另存兼容编码的副本后预览。

## 幻灯片、PSD 或 XMind 与原软件不同

PPTX 提供幻灯片画布，但并不实现全部 Office 排版、动画和特效；ODP 当前是文本预览。PSD 需要保存的合成图。XMind 主要显示主题层级，未完整还原原始样式、关系线、图片和附件。

## 监控没有生成备份

检查 Vertree 是否运行、任务是否暂停、文件是否仍在原位置，以及当前保存距离上一次备份是否超过最小间隔。没有文件变化时不会仅因计时到达而复制。

在监控页打开备份目录检查实际文件，并从设置页打开日志。自动备份受数量上限约束，较旧备份可能已按配置清理。

## 版本树少了文件或分支

树按同目录、同逻辑名称和版本命名规则重建。先检查文件是否被移动、改名、修改扩展名或移除版本段，再刷新画布。自动监控目录中的时间戳备份与手动版本树是不同的组织方式。

## Linux 没有托盘或 Files 菜单

GNOME 托盘可能需要启用 AppIndicator 扩展，Files 菜单需要 Nautilus Python 扩展支持。缺少托盘时可从主窗口使用应用。设置页可检查平台集成状态，详情见 [Linux 说明](../linux.md)。

## 关闭预览后，浏览器还留着页面

这是 Linux 外部浏览器的标签页。Vertree 会撤销旧会话，但不会强行关闭你的浏览器标签页；已显示内容可能留在页面中，后续文件读取会失败，可以直接关闭该标签页。

## 本机 API 返回 401 或连接失败

API 默认关闭。先在设置页确认已启用并复制实际地址和本次启动的 Token，业务请求携带 `Authorization: Bearer <token>`。端口可能因占用而递增，重启后应重新获取 Token。详情见[本机 API 与开发控制器](../tutorial-develop/local-api.md)。
