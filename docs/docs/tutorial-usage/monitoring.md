# 监控与自动快照


自动监控适合持续编辑的单个文件。它在发生变化后按间隔留档，不会在文件没有变化时持续复制，也不能替代重要节点的手动备份。

## 添加和检查任务

从首页进入“监控”并添加文件，或在系统文件菜单执行“监控文件”。编辑并保存后，检查任务状态；需要确认结果时打开该任务的备份目录。

![使用测试文件展示的监控任务页面](/img/usage/monitor-tasks-page.png)

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| 备份时间间隔 | 5 分钟 | 从上次成功快照计算的最小间隔 |
| 备份最多数量 | 50 | 每任务已识别快照的保留上限 |

只有写入磁盘的内容才能进入快照。间隔内的多次保存可以合并处理，不能据此要求每次 Ctrl+S 都出现一份备份。复制期间又发生变化，会继续安排处理；故障时以任务状态和日志为准。

## 快照放在哪里

```text
源文件所在目录/
  .vertree/
    snapshots/
      <任务 UUID>/
        <快照 UUID>.<扩展名>
        <快照 UUID>.json
```

内容文件与 JSON 清单配对，清单用于确认归属。不要把这些清单与应用的 `settings.json` 混淆：它们是快照数据，不是第二份应用配置。

成功提交新快照后才处理数量上限，只清理当前任务中验证通过的旧快照。未知文件、损坏清单与旧 `*_bak` 目录不会被猜测性删除。

## 暂停、移除和清理不同

暂停停止后续监控，保留任务。恢复继续监听。移除任务会停止监听并保留归档身份与快照；重新添加相同路径可以复用该身份。

清理快照是另一个磁盘删除动作，只处理已识别且属于本任务的快照，执行前核对确认框。不要把“从列表移除”理解为清空全部备份。

## 运行与存储边界

Vertree 完全退出后不会继续监控。要登录后自动运行，可在设置中开启自启动；“启动后隐藏到托盘”只针对自启动触发，不影响手动打开主窗口。

本地副本无法防止整块磁盘损坏，请把重要成果另存到独立备份位置。通用快速删除也可能删除所选目录内的备份，因此删除前应检查目标范围。

3.0.0 执行重叠文件操作时会暂时协调相关监控，操作结束后只恢复仍适合继续监听的目标。具体调度与安全边界见[监控架构](../tutorial-develop/monitor.md)。
