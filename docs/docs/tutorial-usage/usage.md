# 备份、监控与版本树

## 第一次使用：保留一个阶段版本

以 `方案.docx` 为例：

1. 在原软件中保存文件。
2. 从系统文件菜单选择 Vertree 的“备份文件”；需要快速留档时选择“快速备份”。
3. 普通备份可填写备注，例如“客户确认”。完成后，原目录会出现带版本号的新文件。
4. 对这个文件打开“查看文件版本树”，查看主线和分支。
5. 想检查内容时，右键版本节点选择“预览”。需要编辑时，用系统程序打开文件。

备份通过复制文件创建新版本，不会把多个版本压缩进一个专有数据库。普通文件作为初始版本参与版本树；新增版本和备注会写入文件名。

## 理解版本文件名

```text
方案.docx
方案#客户确认.0.1.docx
方案#备选方向.0.1-0.0.docx
```

`#` 后面是备注，`0.1` 表示主线上的版本，后续由 `-` 分隔的部分表示分支路径。分支编号由当前目录中已有版本决定，不必手工编号。

修改文件名中的逻辑名称、扩展名或版本部分，会影响 Vertree 对文件关系的识别。需要修改备注时优先使用应用提供的操作。完整规则见[版本树设计解析](../tutorial-develop/filetree.md)。

## 从旧版本继续修改

先预览旧版本，确认它是想要的起点，再从该节点创建备份或分支，然后编辑新生成的文件。这样旧版本仍作为原有记录保留。

当“下一个版本号”已被占用时，普通备份会自动生成一个分支，不覆盖已有文件。新建备份和修改文件内容是两个动作：Vertree 负责复制，实际编辑仍在原软件中进行。

## 自动监控

对持续编辑的文件选择“监控文件”，也可以在监控页添加任务。任务会监听文件变化，在符合备份间隔时创建自动快照，保存在文件旁边的 `.vertree/snapshots` 下，每个任务使用独立目录。旧版本的 `*_bak` 目录不会自动导入或删除。

| 设置 | 含义 | 默认值 |
| --- | --- | --- |
| 监控备份间隔 | 两次自动备份之间的最小间隔，不是无变化时也定期复制 | 5 分钟 |
| 最大备份数 | 每个监控任务保留的自动备份数量，超出后删除较旧备份 | 50 个 |

自动监控不会保证每次按保存键都产生一个备份。交付前或重要修改前，建议额外做一次手动备份。

监控页支持添加任务、暂停或恢复、移除任务、打开备份目录、清理备份及清理无效任务。删除监控任务与清理磁盘备份是不同操作，执行前注意对应动作说明。

监控只有在 Vertree 运行时才会工作。若希望登录后自动监控，可在设置页启用开机自启；任务状态会随配置恢复。

## 版本树操作

版本树展示当前目录内同一逻辑文件的主线和分支。选择节点查看文件信息，并使用节点操作进行预览、打开、备份或局域网分享。

画布支持拖动、缩放和重新适配视图。文件在外部新增或改变后，可使用刷新按钮重新读取目录。1.1.0 已去掉整个画布的外层边框和包边，节点自身仍保留轮廓。

版本树依赖文件实际所在位置。将一部分历史版本移动到其他目录后，它们不会继续出现在原目录的树中。

## 常用设置

| 设置区域 | 可以调整什么 |
| --- | --- |
| 外观 | 语言、浅色 / 深色 / 跟随系统 |
| 监控 | 备份间隔、每任务保留数量 |
| 系统集成 | 右键菜单、自启动、托盘或菜单栏行为，依平台而异 |
| 本机 API | 开关、实际监听地址、Token 和文档入口 |
| 维护 | 打开配置文件、日志目录，检查版本更新 |

遇到备份没有生成、版本树缺少节点等问题，见[常见问题](troubleshooting.md)。预览和分享的详细用法分别见[文件预览](preview.md)、[局域网分享](sharing.md)。
