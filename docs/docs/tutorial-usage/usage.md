# 备份、监控与版本树


Vertree 把“保留一个阶段”和“记录编辑过程”分成两条路径。先明确要保留什么，再选择动作。

## 第一次使用：保留一个阶段版本

保存文件后执行“备份文件”，填写备注；新副本带版本号保存在原目录。打开版本树查看关系，再从节点预览内容。完整步骤见[快速开始](quick-start.md)。

## 理解版本文件名

```text
方案.docx
方案#客户确认.0.1.docx
方案#备选方向.0.1-0.0.docx
```

`#` 后是备注，`.` 与 `-` 组合的数字表达主线和分支。编号由已有文件决定，不需要手动分配。修改逻辑名称、扩展名或版本段会改变识别结果，详见[版本树与分支](version-tree.md)。

## 从旧版本继续修改

先预览确认起点，再创建新备份或分支，编辑新副本。不要直接打开旧版本覆盖它，再期待历史保持不变。自动创建模式遇到已有后继会寻找分支；显式 next 模式会报告冲突，而不是覆盖同名目标。

## 自动监控

监控监听单个文件的变化，符合最小间隔后创建快照。默认间隔 5 分钟、每任务保留 50 份；文件位于 `.vertree/snapshots/<任务 UUID>`。旧 `*_bak` 目录不自动导入或删除。

监控记录的是保存过程，手动备份保留的是阶段节点。它们使用不同的文件组织与清理规则。暂停、移除任务、清理快照的区别见[监控指南](monitoring.md)。

## 版本树操作

版本树读取同目录中的同族文件，展示主线和分支。可以拖动画布、缩放、刷新，选择节点预览、打开、创建版本或分享。

在外部移动或重命名部分版本后，树可能缺少节点。先核对文件是否仍在该目录，以及命名是否正确；不要为了“修复显示”直接删除异常文件。详见[版本树指南](version-tree.md)。

## 常用设置

语言、主题、监控间隔、保留数量、系统菜单和本机 API 都在“设置”。首页显示“监控”“设置”和无边框退出图标。随机文案每次完全启动选择一条，同次运行返回首页保持不变。

[设置与配置文件](settings.md)说明默认值和持久化字段；[预览](preview.md)与[分享](sharing.md)各有独立指南。
