# 查看与解除文件占用


:::info Windows 3.0.0
本页面对应 Windows 3.0.0 的文件工具。交互参考 PowerToys File Locksmith，不需要安装 PowerToys，也不提供驱动级强制解锁。
:::

此功能只查看并处理占用进程，**不会删除所选文件**。要清理文件需单独进入[快速删除](fast-delete.md)。

## 查看正在使用文件的程序

选中文件或目录，从右键菜单进入“查看／解除文件占用”。页面按进程展示名称、PID 和“结束任务”按钮，展开卡片查看程序路径、用户与相关文件。多选时合并查询，目录检测不是先遍历里面的全部文件。

点击刷新重新查询。没有找到可访问进程不代表完全没有占用：权限限制、查询超时或结果上限都可能导致扫描不完整。

## 先保存，再结束任务

确认目标应用并保存工作，优先从该程序自身正常关闭。仍需要处理时，在对应卡片点击“结束任务”，核对进程并确认。操作后列表重新扫描，不能只凭发出结束请求就认定成功。

结束进程可能影响这个程序打开的其他文件，未保存内容可能丢失。这不是“无损释放一个文件句柄”。页面没有“强关其他进程的单个句柄”或“一键结束全部进程树”的动作。

## 什么时候使用管理员扫描

普通扫描提示部分进程不可访问时，可点击盾牌图标重新扫描并接受系统 UAC 确认。仅相关辅助进程提权，主程序不会长期以管理员运行。提权后的进程操作仍可能要求原生安全确认。

关键进程、受保护进程、无法验证身份的进程以及 VerTree 自身不会被随意结束。更高权限也不能保证解除所有占用。

## 结果怎么理解

| 现象 | 含义或下一步 |
| --- | --- |
| 进程正在使用文件 | 不一定阻止删除，还取决于其共享打开方式 |
| 无占用结果，但文件仍无法操作 | 还可能是权限、设备状态或其他系统限制 |
| 扫描不完整 | 刷新或按需管理员扫描，保留未能检查的提示 |
| NAS 上仍被占用 | 本机扫描不承诺识别或结束服务器、其他客户端上的进程 |

自动删除只在实际失败后按需处理阻碍，独立占用页面始终由你选择进程并确认操作。更多排查见[常见问题](troubleshooting.md)。
