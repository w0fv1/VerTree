# 快速删除（Windows）


:::warning Windows 3.0.0 · 永久删除
此功能从 Windows 3.0.0 开始提供。删除不进入回收站；确认后会清除只读属性，并可能结束可处理的占用进程。请先保存所有相关程序中的工作内容。
:::

快速删除与解除占用是两个独立页面。这里的目的就是删除；只想查找哪个程序正在使用文件，请改用[解除占用](file-locks.md)。

## 操作顺序

在资源管理器中选中文件或文件夹，右键进入 Vertree 的“快速删除（永久）”。多选目标会一并带入页面；需要添加目标时点击选择卡片即可，没有手动路径输入框或并发设置。

核对确认框中的完整路径与永久删除、结束程序的风险，然后确认一次开始。取消确认不会执行删除。任务只显示当前进度和未完成项目，不提供“本次会话任务”或“本机历史任务”面板。

## 大文件和海量小文件

大文件直接执行删除相关操作，不读取、哈希或覆盖整个文件内容。大量小文件边枚举边处理，队列和线程预算有上限，不需要先把几十万个路径装入内存。

并发由设备与任务预算自动控制，不需要手选线程数，也不是线程越多越快。开始时目录总数可能未知，不能为了进度百分比先完整扫描一遍。

## 会自动处理哪些阻碍

先处理能删除的项目；只读属性按本次确认授权清除；真正失败的项目集中检查占用，处理符合安全条件的进程，再有限次重试。已完成分支不会为了重试重新删除一遍。

不会自动夺取所有权、修改 ACL、关闭安全软件、结束关键系统进程或进程树。权限不足、设备断开、对象身份变化与目录继续新增文件会分别留下失败结果。**“自动处理”不代表绕过所有 Windows 保护。**

## 停止和部分失败

点击“停止”后停止接收后续工作，等待已开始操作在安全边界收尾。已删除内容不会恢复。部分失败不应显示成全部成功；展开未删除项目检查具体错误。

同一路径出现新对象，不继承旧对象的删除授权。应用重启不会自动续删历史任务。辅助报告用于排查，不是文件恢复点。

## 必须知道的边界

普通符号链接和 junction 只删除链接本身，不递归到链接目标。卷挂载点、未知或云占位重解析类型可能拒绝；不能确认稳定身份的文件系统不会降级为不安全的字符串路径删除。

删除名称与磁盘空间完全释放可能不在同一时刻，其他句柄仍可能使释放延后。显示的已处理文件大小不等于实际释放空间。此功能不是安全擦除，不承诺让数据无法恢复。

当前原生目录栈有深度预算；极深目录、HDD、SMB、云同步目录和特殊文件系统需要单独验证。本机 NTFS 测试不代表所有设备都能达到同样速度。

实现、测试与限制见[文件工具架构](../tutorial-develop/file-tools.md)。
