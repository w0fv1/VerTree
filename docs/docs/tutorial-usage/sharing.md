# 局域网分享


将某一版文件发给同一网络中的设备，不需要把文件内容上传到官网。分享期间由运行 Vertree 的电脑提供内容。

## 发起与接收

从版本树节点选择“分享到局域网”，或使用文件菜单与 `vertree share "文件路径"`。把弹窗中的短链接或二维码交给接收方，并保持 Vertree 运行。

接收方打开完整链接后，分享页尝试连接发送端。成功后打开局域网下载页；自动连接失败时，可检查网络与权限提示，再尝试列出的手动地址。两台设备需要能够相互访问，仅仅 Wi-Fi 名称相同并不保证路由器允许互通。

## 链接与文件的边界

`https://vertree.w0fv1.dev/f#...` 是选路页面。`#` 后的内容携带临时分享标识与候选私网地址，不包含本地绝对路径；文件内容从局域网发送端取得。

单独打开 `/f` 不会自动找到文件，需要分享者给出完整链接。临时链接是一种访问凭据：只给需要接收的人，不贴到公开日志或截图中。

退出 Vertree 后进程内分享失效，重新启动不恢复原链接。过期、撤销或相关资源被文件操作释放后，应重新创建分享。

## 连接不通时

| 检查项 | 可以怎么做 |
| --- | --- |
| 接收设备在蜂窝或访客网络 | 切换到能访问发送端的网络 |
| 同一网络仍不通 | 检查客户端隔离、VPN 和防火墙，仅放行确实需要的应用访问 |
| 浏览器弹出本地网络提示 | 在确认分享来源后允许该次访问，再重试 |
| 自动连接失败 | 尝试实际网卡对应的手动下载页；失败也可能是网络限制，不一定是权限 |
| 曾经可用，现在失效 | 检查发送端进程、有效期和是否已撤销 |

不要把预览的本机临时地址当作分享链接。预览、局域网分享与[本机 API](../tutorial-develop/local-api.md)独立管理，打开预览不会自动向局域网分享文件。
