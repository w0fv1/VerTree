# 局域网分享

局域网分享用于把某个文件或历史版本发送给同一网络里的设备。文件由运行 Vertree 的电脑直接提供，不上传到公网服务器。

## 发起分享

1. 在版本树中右键目标节点，选择“分享到局域网”。也可以使用 Windows 文件菜单或 `vertree share "文件路径"`。
2. 将弹窗中的短链接或二维码交给接收方。
3. 接收方在浏览器打开分享页；电脑与接收设备需要能够通过局域网互相访问。
4. 分享页探测可达地址，成功后开始下载。若自动探测失败，可选择页面列出的直连地址。
5. 分享期间保持 Vertree 运行，并留意弹窗中的有效期。

## 分享链接与文件内容

分享页使用 `https://vertree.w0fv1.dev/f#...` 形式。链接中包含临时分享键和候选私网地址，不包含本地绝对文件路径。

公网文档站提供选路页面，文件传输走局域网。拿到链接且能访问发送端网络的设备可以使用该临时分享，因此请按文件的实际用途分发链接。

退出 Vertree 后进程内的分享失效；重新启动不会自动恢复原有临时链接。过期或已撤销的分享需要重新创建。

## 连接失败时

| 现象 | 先检查什么 |
| --- | --- |
| 手机打不开下载地址 | 手机是否连接同一 Wi-Fi；是否在使用蜂窝网络或访客网络 |
| 同一 Wi-Fi 仍失败 | 路由器是否启用客户端隔离；系统防火墙是否允许应用在当前网络接收连接 |
| 浏览器提示本地网络权限 | 允许本次访问后重试；也可使用页面提供的直连地址 |
| 自动选路失败 | VPN、虚拟网卡可能产生不可达候选地址，尝试实际局域网接口对应的地址 |
| 链接以前有效，现在失效 | 检查发送端是否退出、分享是否过期或已撤销 |

文件预览使用的本机临时地址不能当作局域网分享链接。要让其他设备读取文件，应明确使用“分享到局域网”。

开发者可通过本机 API 创建、查询和撤销分享，见[本机 API](../tutorial-develop/local-api.md)。
