# 后续规划

以下以 **3.0.0** 为基线列出实现状态和后续方向，不构成交付时间承诺。

## 3.0.0 已实现

Windows 快速删除与占用查询、两套菜单逐项设置、单配置文件收口、启动随机文案与比例首页卡片已经进入源码。这些能力随 3.0.0 提供，其中删除与解除占用仅适用于 Windows。删除与占用的范围、保护策略与测试见[文件工具架构](file-tools.md)。

## 仍需补充的验收

HDD、SMB、特殊文件系统、云占位文件与不同 UAC 策略各自需要实机验证。Windows 的回归结果不能替代 macOS / Linux；本地网站预览也不等于 GitHub Pages 已上线。

## 预览兼容性

- 提升复杂 Office 文档与幻灯片的版式还原。
- 将 OpenDocument 演示从文本预览推进到更完整的画面。
- 补齐 XMind 图片、附件、关系线与样式。
- 评估旧 DOC/PPT、MSG、MOBI/AZW 等专有格式，先确认解析质量与维护成本。
- 扩大 macOS / Linux 原生预览和不同媒体编码的实机回归覆盖。

## 大文件与稳定性

- 降低仍需完整解析的文档和压缩文件的内存占用。
- 改善大文件快照准备阶段的进度与取消体验。
- 优化复杂版本树的布局、缩放和重绘开销。

## 分发与系统集成

- 持续改善 Windows 11 包身份和菜单注册的安装体验。
- 完善 macOS 签名、公证与分发。
- 扩展 Linux 非 GNOME 桌面的集成与排障说明。

## 文件管理与文档质量

- 探索版本搜索、备注管理和差异展示。
- 保持 UI、CLI 与 API 的操作语义一致。
- 持续维护真实样例、文档与发布工件之间的一致性。
- 在文档生产构建后逐路由检查链接、移动端溢出、暗色主题与资源加载。
- 发布前核对下载附件，不把开发功能混入正式版安装说明。
